# Установка FreeTurn для Windows

Это локальная preview-поставка Windows10/11 x64. Запустите Setup, подтвердите стандартный запрос Windows и следуйте русскому мастеру. Приложение появится в меню «Пуск»; ярлык на рабочем столе можно выбрать отдельно. Установка не подключает VPN и не закрывает другие приложения. Если FreeTurn открыт, сначала закройте его вместе со значком в трее.

Профили и настройки сохраняются в прежнем зашифрованном хранилище пользователя. При первом подключении приложение само проверит и при необходимости подготовит сетевое ядро; для этого Windows может отдельно запросить разрешение. Установка интерфейса не заменяет владельца уже существующих служб. Обычные portable-сборки и старые архивы можно сохранить.

Для обновления вручную запустите новый Setup из доверенного источника. Нужны отключённый FreeTurn VPN и закрытое приложение. Более старая версия не заменяет установленную новую. Повторная установка той же версии служит восстановлением файлов; настройки и ключи сохраняются. Автоматического скачивания обновлений в этой preview нет.

Удаление доступно в параметрах Windows → Приложения → FreeTurn. Сначала отключите VPN и закройте FreeTurn. После обычного подтверждения удаляются интерфейс и только его проверенные сетевые службы/фиксированные исполняемые файлы. Допускается удаление подтверждённо собственной частичной установки, если её туннель не активен и сохранён владелец; неизвестные службы не усыновляются. Данные профилей в LocalAppData и ProgramData сохраняются. После удаления сохранённые данные могут быть повторно использованы только прежним пользователем Windows. Неизвестные файлы и другие VPN не удаляются; перезагрузка автоматически не запускается. Записи автозапуска удаляются только при точном совпадении команды этой установки в загруженных пользовательских профилях; write-доступ запрашивается только после проверки и повторной сверки. Недоступные чужие и незагруженные Windows-профили не монтируются и не правятся.

Установка находится в фиксированной защищённой папке Program Files/FreeTurn; сетевое ядро использует прежнюю отдельную Program Files/FreeTurnManager. Никаких загрузок или команд администрирования VPS мастер не выполняет.

Поставка пока **не подписана издателем**: Windows может показывать неизвестного издателя/SmartScreen. SHA256 помогает сверить файл, но не заменяет доверенную подпись. Доверенный сервер обновлений и ключ издателя ещё не настроены. Не включайте необслуживаемое интернет-обновление по одному совпавшему SHA256.

Мастер построен на [Inno Setup7.1.1](https://jrsoftware.org/inno-setup/downloads); его исходная лицензия включена в поставку. Код FreeTurn и компонентов входит в Windows-Client-Sources.zip, код установочной обвязки и helper — в FreeTurn-Setup-Sources.zip. Go/x/sys notices уже входят в THIRD_PARTY_NOTICES.txt. Лицензия кода клиента — Android-LICENSE.txt (GPL-3.0); требования существующих компонентов сохраняются.

Сборка разработчиком: `python clients/windows/installer/build_setup.py --go C:/VPNN/.toolchains/go/bin/go.exe --compiler .local-cache/tools/Inno-7.1.1`. Скрипт проверяет закреплённый компилятор и frozen0.25 payload, собирает/проверяет guard и компилирует отдельный Setup. Он не запускает полученный установщик, не меняет службы или сеть. Реальные install/upgrade/uninstall/UAC/чистая Windows VM проверки выполняются отдельно; локальная компиляция не является их подтверждением.

Для воспроизведения из отдельного source bundle разместите его содержимое в clients/windows/installer внутри пустого рабочего дерева, а соответствующий frozen FreeTurn-Windows-VERSION-preview-win-x64.zip —в clients/windows/artifacts. Компилятор задаётся явным --compiler; downloaded compiler/container в source bundle не включаются. Версия/payload hash берутся из включённого toolchain.lock.json.
