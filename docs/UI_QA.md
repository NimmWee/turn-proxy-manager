# Проверка первой панели

Среда: реальный FastAPI на тестовом VPS, Unix RPC и kernel WG; браузер с локальным SSH forwarding. Это не mock данных и не испытание телефона. Playwright Interactive используется как инструмент действий в браузере, не для покрытия каждого компонента тестом.

Перед проверкой: production build PASS, API auth/CSRF/Origin/logout и body-limit проверены целевыми тестами. Статус ниже обновляется по фактическим действиям.

| Сценарий | Проверка | Результат |
| --- | --- | --- |
| Вход | Ошибка пароля, затем правильный вход через форму; logout и повторный вход | PASS |
| Обзор | Реальные CPU/RAM/traffic, refresh, появление графика после новых samples | PASS |
| Навигация | Обзор / пользователи / устройства | PASS |
| Пользователь | Добавить, найти, отключить/включить отдельного тестового пользователя | PASS |
| Устройство | Добавить synthetic public key, проверить kernel peer, отключить/включить; не менять legacy iPhone | PASS, 3 peers во время проверки, 2 после cleanup |
| Формы | Отмена/Escape, pending state, подтверждение отзыва | PASS |
| Отключённые | Фильтр и пустой результат поиска | PASS |
| Темы | Light → dark → light; читаемость статусов и форм | PASS, снимки просмотрены после завершения transition |
| Мобильный вид | 390×844: вход, навигация, карточки вместо таблиц, формы и отсутствие горизонтального overflow | PASS, input 16 px; эмуляция браузера |
| Сохранность | Исходные config/profile и MainPID VPN/SSH после CRUD не изменены | PASS |

Скриншоты — в ignored `logs/`; пароли, cookies и секретный URL в документацию не копировать. Реальные iPhone/Android/Windows E2E, публичный HTTPS и чистый VPS restore пока не являются результатом этой проверки.
