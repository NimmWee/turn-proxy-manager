# Вертикальное окно и редактирование подключения

15.11.2026, Windows preview0.3.0. Продолжение переноса Android5.3.4 по поручению пользователя; без субагентов, без обновления установленной службы и без переключения VPN.

## Поведение

Основное окно480×860 DIP, min width420, высота ограничена рабочей областью экрана. Пять исходных нижних вкладок сохранены; длинные формы прокручиваются, кнопки переходят на следующую строку. Список серверов и редактор также вертикальные. Редактор доступен через «Серверы → Параметры» для уже импортированного поддерживаемого профиля.

Редактируются имя, peer IP:port, masked VK call link, n/spc, auto/plain/doh resolver и список DNS, manual CAPTCHA. WG-конфигурация скрыта до явного раскрытия. Это не реализация split DNS, доменных правил или новых транспортов. Engine проверяет исходную ссылку перед открытием и результат перед сохранением; unsupported профиль не преобразуется молча в урезанный формат.

## Сохранность данных

`ShareDocument` клонирует весь исходный JSON и заменяет только поля редактора. Неизменённый WG остаётся побайтно тем же значением строки, включая переводы строк; сравнение ведётся с исходным отображением WPF, чтобы нормализация TextBox сама не считалась правкой. Ключи/PSK/CID и остальные поля не реконструируются из неполной модели. Неизвестные поля codec сохраняет; это не обещание, что engine примет расширения, которых он не поддерживает. JSON с повторными именами полей, в том числе вложенными, отклоняется фиксированной ошибкой без исходных значений.

Сохранение атомарно обновляет CurrentUser DPAPI-каталог, сохраняет ID и предыдущий ciphertext. При ошибке/отмене прежняя запись остаётся. Во время проверки форма блокируется. Если изменена локально выбранная запись, её active marker очищается: SYSTEM-профиль ещё прежний. Применение — отдельная существующая authenticated IPC import операция по кнопке «Выбрать», только при отключённом VPN. Никаких live network edits из редактора нет.

## Реальные проверки

- WPF Release publish PASS. Offline renders главной480/420, Добавить/Настройки/Поделиться в420, Логов и editor420 просмотрены: навигация/действия доступны, переполнения обработаны прокруткой/переносом.
- CurrentUser DPAPI scenario PASS: clone/edit key preservation, сохранение opaque/nested fields, explicit WG edit, duplicate refusal, сброс marker только для изменённого active ID, изоляция другого профиля, запрет перезаписи повреждённого каталога. Данные синтетические во временной папке.
- Настоящее окно с синтетическим профилем: invalid peer → понятный отказ, повторно доступная форма; исправление на reserved documentation IP → Save и завершение процесса после engine validation. Каталог пользователя/SYSTEM-профиль в этом developer view не читаются/не пишутся; туннель не запускается. Финальное native capture остановлено пользователем Escape; новые app inputs не выполнялись.
- Финальный `build.ps1` PASS (Go test/vet, Release publish,54 dependency notices); архив0.3.0 содержит12 явно перечисленных файлов,11 checksums совпадают, новые editor sources включены, preview/bin/obj/private artifacts в архив не попали. Baseline23 SHA и vendor package verification PASS.
- Read-only real IPC PASS: VerifiedService=true, Elevated=false, State=stopped, HasProfile=true. Offline import/foreground guards PASS, route/adapter/service digest неизменён. Preflight ожидаемо блокирует VPN из-за `OTHER_VPN_OR_NONPHYSICAL_UPLINK`; текущий сторонний VPN не отключался. Скрипт запускался отдельным `pwsh -NoProfile -File`, чтобы `$LASTEXITCODE` предыдущего вызова не выдавать за результат PowerShell-сценария.
- Реальное редактирование пользовательского профиля с последующим IPC import и Windows VPN E2E **NOT RUN**. Live CAPTCHA, DNS/IPv6 leaks и остальные backend режима остаются открытыми проверками.
