## Что реально проверено

- Go tests: профиль/ключи/права/IPC, Direct×TURN transport×obf, отдельный TCP/KCP/Bond без system routes, SOCKS auth/CONNECT через синтетический stream, запрет anonymous/metadata/private targets, закрытие принятого loopback клиента. Это локальные проверки, не работа транспорта через VPS.
- Native CurrentUser DPAPI/catalog scenario: AES-GCM roundtrip, неправильный пароль и подмена ciphertext, независимый Python PBKDF2/AES-GCM vector с Unicode password, Windows backup merge/retry, Android synthetic source/CID/WG/SSH preservation и сохранность inactive WG. QR raw/PNG roundtrip. Clone/edit, explicit WG edit, duplicate JSON rejection, active-marker isolation, corrupted-catalog refusal. Нет теста на каждый UI-control.
- Повторный Android import и последующий Windows backup сохраняют оба исходных документа: отдельная data-preservation проверка PASS. GUI выбора исторического документа собран; отдельный click-сценарий этого выбора NOT RUN.
- Настоящий SSH loopback server Paramiko4.0.0 с временным RSA host key: неизвестный/изменённый ключ →0 попыток аутентификации, закреплённый →1 успешная password auth. Нет shell/channels/команд. External SSH и private-key auth E2E NOT RUN.
- Native `--check-desktop-ui`: значок зарегистрирован/удалён, окно скрыто/показано, ServicesUsed=false, NetworkChanged=false. Клики по context menu, Explorer restart и реальное HKCU Run изменение NOT RUN; корректное quoting startup command проверено локально.
- Offline renders при420 DIP: основной экран/Добавить/Настройки/Поделиться/editor/backup/QR/SSH/SOCKS, светлая главная/Настройки/editor. Рендеры используют отдельные synthetic catalogs и не запускают службу. Обнаруженная ошибка launcher с лишним невидимым окном исправлена: snapshot-окна завершаются сами.
- Release publish, dependency locks/licenses и package allowlist; native read-only IPC к установленной старой службе возвращает VerifiedService=true, Elevated=false, State=stopped, HasProfile=true. Реальный профиль сохранён.
- Чтение status само не закрывает listener и не перестраивает VPN: закрытие SOCKS при потере связи делает отдельный watchdog/явный disconnect. Каталог0.4 читает старые данные; старые strict readers могут отказать при downgrade, сохранив файл без перезаписи. `ProfileSnapshot`/SSH/SOCKS DTO имеют безопасный `ToString`, исключающий секреты.

Preview/check JSON, bin/obj, runtime/secret artifacts в архив не попали. Go14 targeted tests и vet PASS, WPF Release publish без warnings/errors. `git diff --check` PASS. Baseline23 SHA и vendor binary/runtime package verification PASS. Последний read-only IPC: служба stopped, профиль есть, Elevated=false; owned preview processes завершены. Полный Linux/server suite не повторялся для Windows-only изменений.

## Незавершённое

**Полный перенос не закончен.** Не реализованы native AWG, domain/per-app routing, split DNS/BitTorrent enforcement, установка/управление сервером и выдача/отзыв доступов, camera QR, LAN hotspot, updater и полный набор языков/privacy/system-theme options. Ping/latency UI не перенесён полностью. IPv6 и UDP SOCKS не поддерживаются. Managed client subscriptions/bootstrap из ТЗ не появляются автоматически из Android share import.

В pinned core `internal/tunnel/awg/tun_other.go` прямо возвращает unsupported на Windows: нужен отдельный Windows TUN/backend и управление маршрутами/firewall. WGNT не заменяет AWG. Android VpnService per-app rules также не являются Windows-реализацией. Для этих функций не добавлялись фиктивные переключатели.

**NOT RUN по поручению пользователя:** реальный Windows VPN/Direct/Relay/forwarder/SOCKS egress, live CAPTCHA, DNS/IPv6/leak/route cleanup, установка/upgrade0.4 службы и воспроизведение разрыва на настоящей сети. Установленные0.1.1/телефонные профили/VPS не менялись. Пользователь проверяет сеть отдельно.
