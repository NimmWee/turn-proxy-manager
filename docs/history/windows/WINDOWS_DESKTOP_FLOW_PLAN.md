# Windows: одно окно и подключение с подготовкой ядра

16.11.2026. Поручение пользователя: убрать ручное обновление служб из обычного подключения, пересмотреть desktop flow. Пользователь выбрал компактное вертикальное окно с нижними вкладками и отдельно потребовал открывать разделы в этом же окне. Без субагентов, без запуска реального VPN агентом.

Дизайн: добавить/выбрать локальный профиль → главный экран → «Подключить» → проверка установленного ядра → при необходимости UAC setup из текущего распакованного пакета → повторная аутентификация IPC/проверка версии → применение выбранного профиля → подключение. Отмена UAC, ошибка обновления, неизвестная/более новая версия или неаутентифицированная служба прерывают цепочку. Активный туннель не обновлять и не обрывать; фоновое переподключение не запускает UAC. Профиль, известный только SYSTEM службе, сохраняется и используется без создания новых ключей. Обновления из интернета в этот блок не входят.

Визуальный формат сохраняется; сценарий упрощается: видимая подпись основной кнопки, понятный пустой экран с добавлением сервера, успешный импорт выбирает локальный профиль и возвращает домой; выбор профиля не требует работающей службы. Служба подготавливается при подключении. Серверы/редактор/SSH/SOCKS/маршрутизация/backup открываются внутри общего контейнера с «Назад» и нижней навигацией. У длительных сохраняющих операций возврат заблокирован до завершения. Системные file pickers/UAC/подтверждения остаются штатными диалогами. CAPTCHA WebView интегрируется в основное окно; автоматическая проверка не открывает видимого второго окна.

Рассмотрены: оставить отдельную кнопку update (сохраняет нынешнюю проблему); автоматически запускать setup при каждом подключении (лишние UAC/перезапуски); выбран вариант проверки версии и setup только по необходимости. Для релиза с подписанным installer можно объединить GUI/службы при установке; сейчас используем существующий guarded setup с rollback, не добавляем привилегированный произвольный updater.

Первичные UX-ориентиры: [Proton Windows](https://protonvpn.com/support/protonvpn-windows-vpn-application) — quick connect, выбранные/недавние серверы и отдельные настройки; [Mullvad desktop](https://mullvad.net/en/help/using-mullvad-vpn-app) — главное действие подключения, выбор локации и трей. Это ориентиры сценария, не обещание паритета функций или автоматического обхода UAC.
